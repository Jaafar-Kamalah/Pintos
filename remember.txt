När Pintos låser sig:
Ctrl-a och sedan x för att avsluta emulatorn QEMU. Bekräftas med: 
QEMU: Terminated
Fungerar inte:  öppna en ny terminal och i den kör:
killall pintos
------------------------------------------------------------------------------------------
För att se hur flaggor används:
pintos --help
------------------------------------------------------------------------------------------
QEMU:
<Ctrl-Alt> : i det grafiska fönstret tar eller släpper kontroll
över tangentbord och mus.
<Ctrl-a x> : Avslutar emulatorn. Släpp control innan du trycker på x.
Kan behöva tryckas flitigt för att ge effekt.
------------------------------------------------------------------------------------------
Se hur main avslutades:
echo $?
------------------------------------------------------------------------------------------
Kompilera C:
gcc -Wall -Wextra -std=c99 -pedantic -g assignment1.c

(Programmet kommer heta a.out om du inte döper om det med flaggan -o
Ofta behöver du också lägga till flaggan -m32, för att kompilera i 32-bitarsläge. I och med att Pintos är ett
32-bitars operativsystem är vissa exempel designade för ett 32-bitarssystem. Behövs denna flaggan står det
i kommentaren överst i programfilen.)

GDP
Starta: gdb: -tui ./run
Byt fokus: ctrl + x, o
Korrigera överskrivning: ctrl + l

Starta felsökning: run eller r
Skriv ut variabel: print <data> eller p <data>

Brytpunkt: break <fil>:<rad> eller b <rad> (för filen som visas ovan)
Ta bort bytpunkt: disable/enable <brytpunktnummber>

Fortsätt: continoue eller c

Skriv ut datamedlem efter varje kommando: display <data>
Ta bort display: undisplay <diplay nummer>

Nästa rad: step eller s
Nästa rad & hoppa över funktionsanrop: next eller n
Till slutet av funktionen: finish eller f

visa stacklista: backtrace eller bt
Gå till frame: frame <frame nummer> eller f <frame nummer>
